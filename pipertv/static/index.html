HOW THE CURSOR MOVES

Snapping steps between the controls a page reports. Moving smoothly slides the cursor and speeds up while a direction is held — steadier on a page whose controls Piper cannot see cleanly. At the top or bottom of the screen the page scrolls under the cursor, so a scrollbar never has to be dragged. "Held after" is how long a key must be down before it counts as held and starts repeating — raise it if a single press moves two items.
